## Project Overview

This project analyzes the **Child Mind Institute (CMI) – Problematic Internet Use** dataset, with the aim of investigating the relationship between physical activity, fitness-related variables and problematic internet use in children and adolescents.

The project combines traditional tabular data mining techniques with advanced machine learning, explainability methods and time-series analysis.

## Project Structure

### Tabular Data Analysis

- `00_Tabular_Preparation_Understanding.ipynb`  
  Data understanding, data quality assessment, semantic validation, missing-value imputation and feature engineering.

- `01_Outlier_Detection_Imbalanced_Learning.ipynb`  
  Multivariate outlier detection, dimensionality reduction and imbalanced learning techniques.

- `02_Advanced_Classification_XAI.ipynb`  
  Advanced classification using Logistic Regression, SVM, Neural Networks, Ensemble Methods and Gradient Boosting, followed by explainability analysis.

- `03_Advanced_Regression.ipynb`  
  Advanced regression models for predicting the PCIAT total score.

### Time-Series Analysis

- `04_Time_Series_Preprocessing.ipynb`  
  Data understanding, cleaning and preprocessing of the wearable-sensor time series.

- `05_Time_Series_Motifs&Discords.ipynb`  
  Motif and discord discovery using Matrix Profile techniques.

- `06_Time_Series_Clustering.ipynb`  
  Time-series clustering using K-Means and Hierarchical Clustering.

- `07_Time_Series_Classification&Shapelets.ipynb`  
  Time-series classification using KNN, DTW, MiniROCKET and shapelet-based approaches.

- `08_Time_Series_ShapeletsvsMotifs.ipynb`  
  Comparison between discriminative shapelets and motifs/discords.

## Explainability

The explainability module includes:

- SHAP
- LORE

The `lore/` directory contains the code required for the LORE analysis.
## Key Results

- **Tabular Classification:** Random Forest provided the best overall balance across classes, achieving a macro F1-score of **0.45**.
- **Regression:** LightGBM achieved the best performance for PCIAT score prediction, with **MAE = 13.925**, **RMSE = 17.223**, and **R² = 0.277**.
- **Time-Series Classification:** Random Shapelet Transform combined with Logistic Regression achieved the best macro F1-score (**0.567**), with an F1-score of **0.43** for the problematic-use class.
- **Explainability:** SHAP and LORE were used to investigate both global feature relevance and local classification behavior.
